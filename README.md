## 📋 Project Description

This interactive card form allows users to enter their credit card details and see them reflected on a dynamic preview in real time. The form includes validations for each field, visual feedback for errors, and a responsive design for mobile and desktop devices.

It’s a great exercise in working with forms, accessibility, UX/UI, and JavaScript logic.

## 📌 Key Features

- Real-time credit card data preview  
- Form input validation with visual error messages  
- Responsive layout  
- Custom thank-you message after submission  
- Reset functionality

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Aleji0309/proyectaSixthChallengeCard.git
````

2. Navigate to the project folder:

```bash
cd proyectaSixthChallengeCard
```

3. Open `index.html` in your browser, or use a development server like **Live Server** in VS Code.
